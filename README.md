
# Персональный организатор

## О проекте

«Персональный организатор» — веб-приложение для планирования дня. Оно позволяет управлять списком задач, просматривать случайные цитаты, узнавать текущую погоду в Санкт-Петербурге и записывать заметки.

## Возможности

- **Список дел:** добавление, выполнение и удаление задач.
- **Цитата дня:** загрузка случайной цитаты и её автора из внешнего API.
- **Погода:** отображение текущей погоды в Санкт-Петербурге.
- **Дата и заметки:** отображение даты, приветствия и поле для заметки.
- **Управление виджетами:** добавление, сворачивание, разворачивание и удаление карточек.
- **Адаптивный интерфейс:** расположение карточек подстраивается под ширину экрана.

## Технологии

- HTML5
- CSS3
- JavaScript (ES6 Modules)
- Fetch API
- AbortController
- DummyJSON Quotes API
- Open-Meteo API

## Структура проекта

- `index.html` — основная HTML-страница.
- `main.js` — запуск приложения и обработка кнопок добавления виджетов.
- `js/UIComponent.js` — базовый класс виджета.
- `js/ToDoWidget.js` — виджет списка дел.
- `js/QuoteWidget.js` — виджет цитат.
- `js/WeatherWidget.js` — виджет погоды.
- `js/DateWidget.js` — виджет даты и заметок.
- `js/Dashboard.js` — управление коллекцией виджетов.
- `styles/main.css` — стили приложения.

## Запуск проекта

1. Скачайте или склонируйте репозиторий.
2. Откройте папку проекта в Visual Studio Code.
3. Запустите `index.html` через расширение Live Server.
4. Откройте локальный адрес, который покажет Live Server.

Важно: приложение использует JavaScript-модули, поэтому рекомендуется запускать его через локальный веб-сервер, а не двойным щелчком по HTML-файлу.

## Используемые API

- DummyJSON Quotes API: https://dummyjson.com/quotes/random
- Open-Meteo API: https://api.open-meteo.com/

Для загрузки данных требуется подключение к интернету. При ошибке запроса виджеты показывают сообщение о проблеме.

## Хранение данных

Задачи и заметки хранятся в памяти текущих экземпляров виджетов. После перезагрузки страницы они не сохраняются.

## Использование AI-помощника

AI-помощник использовался для пошагового проектирования и разработки приложения, подготовки структуры HTML, CSS и JavaScript, создания и проверки классов виджетов, подключения API, поиска ошибок и тестирования функций.

Полученные предложения проверялись запуском приложения и ручными проверками. Код и результаты необходимо оценивать с учётом фактической реализации проекта.

## Ограничения

- Для получения цитат и погоды необходим интернет.
- Данные задач и заметок не сохраняются после перезагрузки.
- Погода отображается для Санкт-Петербурга.
